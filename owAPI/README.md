# WebBridge & Application Toolchain

Diese Toolchain besteht aus zwei Hauptkomponenten: **WebBridge** (automatisiert ChatGPT im Browser) und **Application** (orchestriert ChatGPT und ownAPI). Im Folgenden werden Setup, Nutzung und Akzeptanztests beschrieben.

## Setup

1. **Python installieren:** Stellen Sie sicher, dass Python 3.11+ installiert ist.
2. **Abhängigkeiten installieren:** Führen Sie im Projektordner aus:  
   ```bash
   pip install -r requirements.txt
